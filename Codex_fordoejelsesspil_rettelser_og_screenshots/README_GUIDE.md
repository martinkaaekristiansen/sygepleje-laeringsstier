# Sådan bruger du pakken

1. Pak ZIP-filen ud på din computer.
2. Åbn dit GitHub-repository: https://github.com/martinkaaekristiansen/sygepleje-laeringsstier
3. Opret en mappe `docs/codex-fordoejelse/` og upload **alle filer og undermappen `screenshots/`** fra denne pakke dertil. Bevar filnavne og mappestruktur.
4. Commit ændringerne, gerne på en separat branch.
5. Åbn Codex med dette repository og brug instruktionen nedenfor.

**Indsæt i Codex:**

> Gennemgå `docs/codex-fordoejelse/START_HER_CODEX.md`, `BILLEDOVERSIGT.md`, alle billeder i `screenshots/` og `KILDE_hele_worddokumentets_tekst.md`. Gennemgå derefter den eksisterende kode for Fordøjelsens vilde rejse. Bekræft først, at du kan se billederne, og fremlæg en prioriteret plan med hvilke filer du vil ændre. Implementér kun fase A i første omgang, kør relevante tests og vis ændringerne. Vent med fase B-E til jeg godkender resultatet.

Hvis Codex ikke kan læse .docx, kan den stadig læse `.md` og de separate billeder. Billederne er originaler udtrukket af Word, ikke nyskabte illustrationer.
